🔑 키스토어 생성 - 가장 쉬운 방법

⚠️ 중요: 키스토어 파일과 비밀번호는 꼭 백업하세요!

방법 1: Android Studio (권장)

1단계: Android Studio에서 키스토어 생성

  1. Android Studio 열기
  2. Build → Generate Signed Bundle / APK
  3. APK 선택 → Next
  4. Create new 클릭
  5. 키스토어 정보 입력:
    • Key store path: android/app/chunwoo-release-key.jks
    • Password: chunwoo123
    • Alias: chunwoo-key-alias
    • Key password: chunwoo123
  6. OK 클릭

2단계: 릴리즈 APK 빌드

  1. Build → Build Bundle(s) / APK(s) → Build APK(s)
  2. release 선택
  3. 빌드 완료 후 locate 클릭

방법 2: 온라인 도구

온라인 키스토어 생성기

  • APK Signer - 온라인에서 키스토어 생성
  • KeyStore Explorer - 데스크톱 앱

APK 파일 위치

android/app/build/outputs/apk/release/app-release.apk

Google Play 업로드 준비

  1. Google Play Console 접속
  2. 새 앱 만들기
  3. 앱 정보 입력
  4. APK 업로드
  5. 스토어 등록 정보 입력
  6. 출시
💡 팁: 처음에는 내부 테스트로 출시하여 테스트한 후, 점진적으로 확대하세요.
