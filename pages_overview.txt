[페이지별 기능 정리]

1. CustomSchedule.jsx (달력 기반 일정 관리)
   주요 기능: 달력 UI, 일정 관리
   세부 기능:
   - 드래그앤드롭 일정 이동
   - 일정 추가/삭제
   - 날짜별 일정 개수 표시
   연동 기능:
   - Firebase 연동
   - 엑셀 내보내기

2. ImportantSite.jsx (주요현장 관리)
   주요 기능: 현장 정보 관리
   세부 기능:
   - 카드형 UI
   - 현장 정보 표시
   - 진행률 입력
   - 기성/안전/토론 버튼
   연동 기능:
   - Firebase 연동
   - 차트 표시
   - 계약금 대비 분석

3. Dashboard.jsx (대시보드)
   주요 기능: 전체 현황 모니터링
   세부 기능:
   - 전체 현장 현황
   - 오늘의 일정
   - 주요 지표 모니터링
   연동 기능:
   - 데이터 시각화
   - 차트/그래프

4. Sites.jsx (현장 관리)
   주요 기능: 현장 정보 관리
   세부 기능:
   - 현장 목록 관리
   - 현장 정보 CRUD
   - 검색/필터링
   연동 기능:
   - Firebase 연동
   - 상세 정보 관리

5. Reports.jsx (보고서)
   주요 기능: 보고서 생성
   세부 기능:
   - 현장별 보고서
   - 데이터 분석
   - 통계
   연동 기능:
   - 보고서 내보내기
   - 데이터 시각화

6. Calendar.jsx (일정표)
   주요 기능: 일정 관리
   세부 기능:
   - 전체 일정 캘린더
   - 월간/주간/일간 보기
   - 일정 필터링
   연동 기능:
   - 일정 관리
   - 필터링

7. Discussions.jsx (토론)
   주요 기능: 커뮤니케이션
   세부 기능:
   - 현장별 토론
   - 댓글/답변
   - 파일 첨부
   연동 기능:
   - 실시간 업데이트
   - 파일 관리

8. Safety.jsx (안전관리)
   주요 기능: 안전 관리
   세부 기능:
   - 안전 문서 관리
   - 안전 점검 기록
   - 사고/예방 관리
   연동 기능:
   - 문서 관리
   - 기록 추적

9. Cost.jsx (비용관리)
   주요 기능: 재무 관리
   세부 기능:
   - 예산/지출 관리
   - 비용 추적
   - 결산 보고서
   연동 기능:
   - 데이터 분석
   - 보고서 생성

10. Settings.jsx (설정)
    주요 기능: 시스템 설정
    세부 기능:
    - 시스템 설정
    - 사용자 권한
    - 알림 설정
    연동 기능:
    - 권한 관리
    - 시스템 관리

11. Progress.jsx (진행상황)
    주요 기능: 진행률 관리
    세부 기능:
    - 진행률 관리
    - 일정 대비 진행
    - 지연 사항 추적
    연동 기능:
    - 진행률 분석
    - 지연 관리

12. Users.jsx (사용자관리)
    주요 기능: 사용자 관리
    세부 기능:
    - 계정 관리
    - 권한 설정
    - 활동 로그
    연동 기능:
    - 권한 관리
    - 로그 추적

13. Overview.jsx (개요)
    주요 기능: 전체 요약
    세부 기능:
    - 현장 요약
    - 주요 지표
    - 알림/공지
    연동 기능:
    - 데이터 요약
    - 알림 관리

14. Members.jsx (멤버관리)
    주요 기능: 팀 관리
    세부 기능:
    - 팀원 관리
    - 역할/책임 설정
    - 연락처 정보
    연동 기능:
    - 팀 관리
    - 연락처 관리

15. Permissions.jsx (권한관리)
    주요 기능: 접근 제어
    세부 기능:
    - 세부 권한 설정
    - 접근 제어
    - 권한 그룹
    연동 기능:
    - 보안 관리
    - 접근 관리

16. Vendors.jsx (협력업체)
    주요 기능: 협력업체 관리
    세부 기능:
    - 협력업체 정보
    - 계약 관리
    - 평가/이력
    연동 기능:
    - 계약 관리
    - 평가 시스템

17. Documents.jsx (문서관리)
    주요 기능: 문서 관리
    세부 기능:
    - 문서 저장/관리

    연동 기능:
    - 파일 관리
