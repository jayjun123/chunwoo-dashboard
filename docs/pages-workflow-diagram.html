랜딩 → 인증 → 페이지 연동 및 기능

n8n / Make.com 스타일 노드 기반 · 랜딩페이지부터 각 페이지 연동과 주요 기능

연동 흐름 (Flow)
랜딩 / → 로그인 / 회원가입 → ProtectedRoute → Layout (메뉴) → 대시보드/일정 (기본) → 메뉴 클릭 → 각 페이지
① 진입 (Entry)
🏠 랜딩페이지 / , /landing, /home 로그인·회원가입 버튼비로그인 진입점
② 인증 (Auth)
🔐 로그인 /login, /auth Firebase Auth이메일/비밀번호
📝 회원가입 /register 가입 후 /register-success
🔑 비밀번호 찾기 /forgot-password 이메일로 재설정 링크
③ 공통 레이아웃 (ProtectedRoute + Layout)
📐 Layout 로그인 후 모든 메인 페이지 사이드 메뉴(일정·현장·기성·견적 등)헤더·알림·프로필하단 네비(모바일)권한별 메뉴 노출
④ 일정
📅 일정관리 /schedule, /dashboard, /d 캘린더·일정 CRUD견적/입찰 일정 연동날씨·체크엑셀 다운로드
📊 현장일정(간트) /gantt, /g 간트 차트현장별 일정히트맵 탭
⑤ 현장
🏗️ 현장관리 /sites, /st 현장 목록·등록·수정·삭제물량내역·계약서 업로드/미리보기기성현황·참여회사
📋 현장 상세 /sites/:siteName 단일 현장 상세SiteDetail 컴포넌트
📊 회사별 현장 /company-distribution, /cd 기간 설정·연도/일자회사별 그룹·총계약금액엑셀 다운로드(번호·회사명)
📄 전체 리스트 /whole-list, /wl 전체 현장 목록날짜/상태 필터
⭐ 주요현장 /importantsite, /is 즐겨찾기 현장
🗺️ MAP /mapping, /map 지도·현장 위치
⑥ 기성·지출·청구
💰 기성관리 /progress, /p 기성현황·차수별선급금/입금완료 합산엑셀·청구서
📑 기성현황 /gisung, /gs 현장별 기성 테이블입금확인·선급금 행 반영기성등록·청구서 업로드
💸 지출 /cost, /c 현장별 지출·자재/노무/장비 등
📌 청구예정 /claims, /cl 청구예정 목록기성과 연동
📋 정산관리 /settlement, /settlement/:siteId 정산 목록·상세
⑦ 견적
📄 견적요청 /estimates, /es 견적 목록·등록·상태AI 메일 요약에서 적용엑셀·납품계약서
📈 견적 분석 /estimate-analysis 견적 분석 뷰
⑧ 시공·거래처
👷 시공팀 /daema-team, /dt 팀별 카드·진행 현장5열 카드·스크롤
🤝 팀 정산 /team-settlement 팀별 정산
📢 입찰현황 /vendors, /v 입찰·견적 현황
🏢 거래처관리 /vendor-management, /vm 거래처 CRUD
⑨ 안전
🦺 안전관리 /safety, /sf 안전 대시·탭
📋 안전점검 /safety-inspections 점검 목록
⚠️ 사고/사고관리 /safety-accidents 사고 기록
📚 안전교육 /safety-education 교육 이력
📊 안전 보고 /safety-costs 안전 관련 보고
⑩ 기타
💬 토론의견 /discussions, /dc 토론방·댓글
🔒 대외비 /confidential, /cf 대외비 문서·악성미수금
📧 AI 메일 요약 /ai-summary 메일 목록·요약·검색제외 키워드·견적 연동
📐 물량 파악 /quantity-check 물량 확인
✅ 할일 /todo-list, /todo/all 할일 목록
⚙️ 설정 /settings, /set 앱 설정
👤 프로필 /profile, /pr 내 정보
⑪ 관리자
👥 멤버 관리 /members, /m 회원 목록·등록·수정
🔐 권한 관리 /permissions, /pm 메뉴별 권한 설정
👤 사용자 관리 /users, /u 사용자·역할
