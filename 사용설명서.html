🎯 시스템 개요

천우 건설현장관리시스템은 현대적인 웹 기술을 활용한 종합적인 건설현장 관리 솔루션입니다.

🚀 빠른 시작 (3분 완성!)

  1. 1단계: 로그인

    이메일과 비밀번호로 로그인하거나 Google 계정으로 간편 로그인

  2. 2단계: 현장 등록

    메인 메뉴에서 "현장관리" → "+ 새 현장 등록" 클릭

  3. 3단계: 기성 등록

    "기성관리" 메뉴에서 현장별 기성 진행 상황 등록

  4. 4단계: 견적서 업로드

    "견적요청" 메뉴에서 엑셀 견적서 자동 업로드

🌐 웹 기반

브라우저에서 바로 사용 가능한 웹 애플리케이션

📱 모바일 최적화

스마트폰, 태블릿에서 완벽 지원

🔄 실시간 동기화

Firebase 기반 실시간 데이터 동기화

📊 데이터 시각화

차트와 그래프로 직관적인 현황 파악

🔒 보안

사용자별 권한 관리 및 데이터 보호

📄 문서 자동화

견적서, 계약서 자동 생성

🔐 접속 및 로그인

1. 시스템 접속

웹 주소: https://your-domain.com
권장 브라우저: Chrome, Edge, Safari, Firefox (최신 버전)

2. 로그인 방법

  1. 이메일 로그인

    이메일 주소와 비밀번호를 입력하고 "로그인" 버튼을 클릭합니다.

  2. Google 로그인

    "Google로 로그인" 버튼을 클릭하고 Google 계정을 선택하여 권한을 승인합니다.

  3. 비밀번호 찾기

    "비밀번호 찾기"를 클릭하고 이메일 주소를 입력한 후, 이메일로 받은 링크를 통해 비밀번호를 재설정합니다.

3. 회원가입

  1. "회원가입" 버튼을 클릭합니다.
  2. 필수 정보를 입력합니다 (이름, 이메일, 비밀번호).
  3. 이메일 인증을 완료합니다.
  4. 관리자 승인을 기다립니다.

🏢 주요 기능별 사용법

1. 📅 일정관리

기능 설명

현장의 전체 일정을 관리하고 계획을 수립할 수 있는 기능입니다.

일정 등록

  1. "일정관리" 메뉴를 클릭합니다.
  2. "+ 새 일정 등록" 버튼을 클릭합니다.
  3. 일정 정보를 입력합니다:
    • 일정명
    • 시작일/종료일
    • 담당자
    • 우선순위
    • 상세 설명
  4. "저장" 버튼을 클릭합니다.

2. 📊 현장일정 (간트차트)

기능 설명

간트차트 형태로 현장 일정을 시각화하여 관리하는 기능입니다.

간트차트 보기

  1. "현장일정" 메뉴를 클릭합니다.
  2. 현장을 선택하면 해당 현장의 간트차트가 표시됩니다.
  3. 일정을 드래그하여 날짜를 변경할 수 있습니다.
  4. 일정을 더블클릭하여 상세 정보를 수정할 수 있습니다.

3. ⭐ 주요현장

기능 설명

중요한 현장들을 별도로 관리하고 우선순위를 설정하는 기능입니다.

주요현장 설정

  1. "주요현장" 메뉴를 클릭합니다.
  2. 현장 목록에서 ⭐ 아이콘을 클릭하여 주요현장으로 설정합니다.
  3. 주요현장은 별도 탭에서 우선적으로 표시됩니다.

4. 🏢 현장관리

기능 설명

모든 현장의 기본 정보를 등록하고 관리하는 핵심 기능입니다.

현장 등록

  1. "현장관리" 메뉴를 클릭합니다.
  2. "+ 새 현장 등록" 버튼을 클릭합니다.
  3. 필수 정보를 입력합니다:
    • 현장명
    • 현장 주소
    • 계약금액
    • 계약기간 (시작일/종료일)
    • 현장 책임자
    • 시공사 정보
  4. "저장" 버튼을 클릭합니다.

현장 정보 수정

  1. 현장 목록에서 수정할 현장을 클릭합니다.
  2. "수정" 버튼을 클릭합니다.
  3. 정보를 수정한 후 "저장"을 클릭합니다.

5. 🛡️ 안전관리

기능 설명

현장의 안전 점검, 사고 관리, 안전 교육을 체계적으로 관리하는 기능입니다.

안전 점검 등록

  1. "안전관리" 메뉴를 클릭합니다.
  2. "안전점검" 탭을 선택합니다.
  3. "+ 새 점검 등록" 버튼을 클릭합니다.
  4. 점검 정보를 입력합니다:
    • 점검일
    • 점검자
    • 점검 항목
    • 점검 결과
    • 개선사항
  5. "저장" 버튼을 클릭합니다.

6. 📋 견적요청

기능 설명

거래처에 견적을 요청하고 응답을 관리하는 기능입니다.

견적 요청하기

  1. "견적요청" 메뉴를 클릭합니다.
  2. "+ 새 견적요청" 버튼을 클릭합니다.
  3. 견적 정보를 입력합니다:
    • 현장 선택
    • 견적 항목
    • 요청 금액
    • 마감일
    • 요청 내용
  4. 거래처를 선택하고 "요청" 버튼을 클릭합니다.

7. 💬 토론의견

기능 설명

현장 관련 의견을 나누고 토론할 수 있는 커뮤니케이션 기능입니다.

토론 참여하기

  1. "토론의견" 메뉴를 클릭합니다.
  2. 토론 주제를 선택하거나 새 주제를 생성합니다.
  3. 댓글을 작성하여 의견을 남깁니다.
  4. 다른 사용자의 의견에 답글을 달 수 있습니다.

🌐 PWA 설치 및 사용법

PWA 설치 (Chrome/Edge)

  1. 브라우저에서 시스템에 접속합니다.
  2. 주소창 옆의 "설치" 아이콘을 클릭합니다.
  3. "천우현장관리 설치"를 클릭합니다.
  4. 설치 완료 후 홈 화면에 앱 아이콘이 생성됩니다.

PWA 설치 (Safari - iOS)

  1. Safari에서 시스템에 접속합니다.
  2. 하단 "공유" 버튼을 클릭합니다.
  3. "홈 화면에 추가"를 선택합니다.
  4. 앱 이름을 확인한 후 "추가"를 클릭합니다.

PWA의 장점

  • 앱처럼 사용: 홈 화면에서 바로 실행
  • 오프라인 지원: 인터넷 없이도 기본 기능 사용
  • 자동 업데이트: 새 버전 자동 다운로드
  • 푸시 알림: 중요한 알림 받기

🔧 문제해결 및 FAQ

자주 묻는 질문

Q1. 로그인이 안 돼요

A: 다음을 확인해주세요:

  • 이메일 주소와 비밀번호가 정확한지 확인
  • 인터넷 연결 상태 확인
  • 브라우저 캐시 삭제 후 재시도
  • 비밀번호 찾기 기능 사용
Q2. 데이터가 저장되지 않아요

A: 다음을 확인해주세요:

  • 인터넷 연결 상태 확인
  • 필수 항목이 모두 입력되었는지 확인
  • 브라우저 새로고침 후 재시도
  • 관리자에게 문의
Q3. 모바일에서 화면이 깨져 보여요

A: 다음을 시도해주세요:

  • 브라우저 새로고침
  • 브라우저 캐시 삭제
  • 최신 브라우저 사용
  • 가로/세로 모드 전환
Q4. 아이디어패드가 작동하지 않아요

A: 다음을 시도해주세요:

  • 브라우저 새로고침
  • 다른 브라우저 사용
  • 터치/마우스 이벤트 확인
  • 관리자에게 문의
