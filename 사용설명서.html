📊 기성관리

기능 설명

현장별 기성금을 단계별로 관리하고 진행 상황을 추적하는 핵심 기능입니다.

기성금 등록

  1. 기성관리 메뉴: "기성관리" 메뉴 클릭
  2. 새 기성 등록: "+ 새 기성 등록" 버튼 클릭
  3. 정보 입력: 현장명, 기성월, 기성금액, 기성내용 입력
  4. 첨부파일: 필요시 관련 문서 첨부
  5. 저장: 기성 정보 저장

🏢 현장관리

기능 설명

모든 현장의 기본 정보를 등록하고 관리하는 핵심 기능입니다.

현장 등록

  1. 현장관리 메뉴: "현장관리" 메뉴 클릭
  2. 새 현장 등록: "+ 새 현장 등록" 버튼 클릭
  3. 기본 정보 입력: 현장명, 주소, 계약금액, 계약기간 등
  4. 정산페이지 생성: 현장 상세에서 "정산페이지 생성" 클릭
  5. 저장: 현장 정보 저장

🗺️ 현장지도

기능 설명

69개 현장의 위치를 지도에서 확인하고 거리를 측정할 수 있는 기능입니다.

지도 사용법

  1. 현장지도 메뉴: "현장지도" 메뉴 클릭
  2. 현장 위치 확인: 지도에서 현장 마커 클릭
  3. 거리 측정: 측정 도구로 현장 간 거리 확인
  4. 현장 정보: 마커 클릭 시 현장 상세 정보 표시

🛡️ 안전관리

기능 설명

현장의 안전 점검, 사고 관리, 안전 교육을 체계적으로 관리하는 기능입니다.

안전 점검 등록

  1. 안전관리 메뉴: "안전관리" 메뉴 클릭
  2. 안전점검 탭: "안전점검" 탭 선택
  3. 새 점검 등록: "+ 새 점검 등록" 버튼 클릭
  4. 점검 정보 입력: 점검일, 점검자, 점검 항목, 결과 등
  5. 개선사항: 필요한 개선사항 기록

기능 설명

견적 요청하기

  1. 견적요청 메뉴: "견적요청" 메뉴 클릭
  2. 새 견적요청: "+ 새 견적요청" 버튼 클릭
  3. 견적 정보 입력: 현장 선택, 견적 항목, 요청 금액, 마감일
  4. 거래처 선택: 견적을 요청할 거래처 선택
  5. 요청 전송: "요청" 버튼으로 견적 요청 완료

💰 정산관리 시스템

핵심 기능

현장별 수익률을 실시간으로 계산하고 관리하는 시스템입니다.

정산관리 사용법

  1. 현장 등록: 현장관리에서 새 현장 등록
  2. 정산페이지 생성: 현장 상세에서 "정산페이지 생성" 클릭
  3. 기성금 등록: 기성관리에서 현장별 기성금 입력
  4. 지출 등록: 각종 비용(자재비, 인건비, 장비비 등) 입력
  5. 수익률 확인: 정산관리에서 실시간 수익률 확인

정산 데이터 구성

  • 계약금액: 현장 계약 총액
  • 기성금액: 기성관리에서 등록된 기성금
  • 자재비: 정산 상세페이지에서 입력
  • 인건비: 장비비 관리에서 등록
  • 안전관리비: 안전관리비 관리에서 등록
  • 기타비용: 지출관리에서 등록

💡 수익률 계산 공식

수익률 = (기성금액 - 총지출) / 기성금액 × 100

정산관리에서는 이 수익률을 실시간으로 계산하여 차트로 표시합니다.

👥 팀정산 관리

기능 설명

시공팀별 정산 및 급여를 관리하는 시스템입니다.

팀정산 등록

  1. 팀정산 메뉴: "팀정산" 메뉴 클릭
  2. 새 정산 생성: "+ 새 정산" 버튼 클릭
  3. 정보 입력: 팀명, 월, 총액, 지급액 등 입력
  4. 현장 연결: 해당 정산과 관련된 현장 선택
  5. 저장: 정산 정보 저장

팀정산 관리 기능

  • 팀별 정산 현황: 각 팀의 정산 상태 확인
  • 월별 정산: 월별 정산 내역 관리
  • 미지급 관리: 미지급 금액 추적
  • 현장 연결: 정산과 관련 현장 연결

📱 모바일 사용법

모바일 최적화 기능

  • 반응형 디자인: 화면 크기에 맞춰 자동 조정
  • 터치 제스처: 스와이프, 핀치 줌 지원
  • 하단 네비게이션: 주요 기능 빠른 접근
  • 모바일 전용 UI: 터치에 최적화된 인터페이스

PWA 설치

  1. Chrome/Edge: 주소창 옆 "설치" 아이콘 클릭
  2. Safari (iOS): 하단 "공유" → "홈 화면에 추가"
  3. Android: 브라우저 메뉴 → "홈 화면에 추가"

🔧 문제해결

자주 묻는 질문

Q1. 정산관리에서 현장이 보이지 않아요

A: 현장관리에서 해당 현장의 "정산페이지 생성"을 먼저 해주세요.

Q2. 수익률이 0%로 나와요

A: 기성관리에서 기성금을 등록하고, 각종 비용을 입력해주세요.

Q3. 모바일에서 화면이 깨져 보여요

A: 브라우저 새로고침 또는 PWA 재설치를 해주세요.
