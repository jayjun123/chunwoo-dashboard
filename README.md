# MyProject - 건설 현장 관리 시스템

## 🚀 주요 기능

### 📊 데이터 관리
- **현장 관리**: 현장 정보 등록, 수정, 삭제
- **기성 관리**: 기성현황 추적 및 관리
- **지출 관리**: 현장별 지출 내역 관리
- **안전 관리**: 안전 점검, 사고 관리, 안전 교육
- **거래처 관리**: 업체 정보 및 계약 관리

### 🌤 날씨 정보
- **실시간 날씨**: 기상청 API 기반 실시간 날씨 정보
- **5일 예보**: 상세한 5일 날씨 예보
- **지역 검색**: 전국 주요 도시 날씨 검색
- **기상청 데이터**: 공식 기상청 단기예보 API 사용

### 📈 보고서 및 내보내기
- **엑셀 내보내기**: 모든 데이터를 엑셀 형식으로 내보내기 (한글 폰트 지원)
- **PDF 내보내기**: 보고서 및 데이터를 PDF 형식으로 내보내기 (한글 폰트 지원)
- **실시간 차트**: 기성, 지출, 진행률 등 실시간 차트 제공
- **대시보드**: 주요 현황을 한눈에 파악할 수 있는 대시보드

### 💬 커뮤니케이션
- **대화방**: 현장별 대화방 기능
- **파일 공유**: 대화방 내 파일 첨부 및 공유
- **실시간 채팅**: 실시간 메시지 전송

### 🔐 보안 및 권한
- **사용자 인증**: Firebase Authentication 기반 로그인
- **권한 관리**: 마스터/일반회원 권한 구분
- **데이터 보안**: Firestore 기반 안전한 데이터 저장

## 🎨 한글 폰트 지원

### 엑셀 내보내기
- **나눔고딕 폰트** 적용으로 한글 텍스트가 깨지지 않음
- **컬럼 너비 자동 조정**으로 한글 텍스트 가독성 향상
- **숫자 포맷팅** 지원 (천 단위 구분자, 통화 표시)
- **날짜 포맷팅** 지원 (한국어 형식)

### PDF 내보내기
- **나눔고딕 폰트** 적용으로 한글 텍스트 완벽 지원
- **테이블 자동 생성** 및 스타일링
- **페이지 번호** 자동 추가
- **헤더/푸터** 커스터마이징 지원

### 지원하는 내보내기 기능
- ✅ 현장 목록 엑셀/PDF 내보내기
- ✅ 지출 현황 엑셀/PDF 내보내기
- ✅ 기성 현황 엑셀/PDF 내보내기
- ✅ 안전 관리 데이터 엑셀/PDF 내보내기
- ✅ 거래처 현황 엑셀/PDF 내보내기
- ✅ 대화방 내용 엑셀/PDF 내보내기
- ✅ 보고서 엑셀/PDF 내보내기

## 🛠 기술 스택

### Frontend
- **React 18** - 사용자 인터페이스
- **Material-UI** - UI 컴포넌트 라이브러리
- **Redux Toolkit** - 상태 관리
- **React Router** - 라우팅
- **Chart.js** - 차트 및 그래프
- **Leaflet** - 지도 기능

### Backend & Database
- **Firebase** - 백엔드 서비스
- **Firestore** - NoSQL 데이터베이스
- **Firebase Authentication** - 사용자 인증
- **Firebase Storage** - 파일 저장소

### 내보내기 라이브러리
- **XLSX** - 엑셀 파일 생성
- **jsPDF** - PDF 파일 생성
- **jspdf-autotable** - PDF 테이블 생성
- **나눔고딕 폰트** - 한글 폰트 지원

## 📦 설치 및 실행

### 필수 요구사항
- Node.js 16.0 이상
- npm 또는 yarn

### 설치
```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm start

# 프로덕션 빌드
npm run build
```

### 환경 설정
1. Firebase 프로젝트 생성
2. `.env` 파일에 Firebase 설정 추가
3. Firestore 데이터베이스 초기화

## 🔧 주요 설정

### 기상청 API 설정
1. **API 키 발급**: [기상청 API](https://www.data.go.kr/data/15084084/openapi.do)에서 발급
2. **환경 변수 설정**: `.env` 파일에 `VITE_WEATHER_API_KEY=your_api_key` 추가
3. **지역 좌표**: 주요 도시의 nx, ny 좌표는 자동으로 설정됨

### 한글 폰트 설정
- `src/assets/fonts/NanumGothic.js`: 나눔고딕 폰트 파일
- `src/utils/exportUtils.js`: 엑셀/PDF 내보내기 유틸리티
- 모든 내보내기 기능에서 자동으로 한글 폰트 적용

### 테마 설정
- 라이트/다크 모드 지원
- Material-UI 테마 시스템 활용
- 사용자별 테마 설정 저장
